# 技术选型

实际依赖与解析版本以各包的 Cargo.toml 和根 Cargo.lock 为准；本文只记录职责与重要边界。

| 领域 | 组件与用途 |
| --- | --- |
| 服务端 | Rust 2024、Tokio、Axum |
| MCP | 官方 Rust SDK rmcp，Streamable HTTP |
| 权威存储 | MySQL 8.4，保存空间、记忆、修订、来源、Secret、回执与任务 |
| ORM 与迁移 | SeaORM 2，schema-first：Rust migration → MySQL → Entity |
| 检索 | Qdrant 1.20 原生 BM25；可选 embedding 与 RRF 混合召回 |
| 模型调用 | reqwest 调用 OpenAI 兼容 embeddings；同名模型共享并发 |
| 命令行 | Clap；chromie 为客户端，chromie-server 为服务管理入口 |
| Web | Slint 1.18.1 / Rust / Wasm；wasm-bindgen 桥接，wasm-pack 0.15.0 构建 |
| 部署 | Docker Compose；用户持久目录为 config 与 data |

## 依赖职责

- serde / serde_json / schemars：JSON 与 MCP 参数 Schema。
- uuid / time：对象标识、UTC 时间和协议编解码。
- argon2：空间密码的 Argon2id 加盐哈希。
- jsonwebtoken / p256 / cookie：ES256 登录态、持久化实例根私钥和 HttpOnly Cookie。
- hkdf / aes-gcm：从原根私钥按用途派生密钥，执行 Secret 及接入密钥的认证加密。
- age：采用成熟文件格式，为空间迁移包提供口令加密和完整性保护。
- toml_edit：保留已有 TOML 配置及注释，安装 Codex MCP。
- rpassword / rustix：终端隐藏输入，安全设置和恢复 Unix 终端状态。
- sha2 / thiserror / tracing：摘要、领域错误和有限运行诊断；日志不包含凭据或正文。

项目内直接 Rust 库关闭默认 feature；实际 feature 见清单。构建链中的 Rustls 使用 aws-lc-rs。中文字体为 Noto Sans SC，随 Wasm 本地打包，保留原 OFL 许可。

## 客户端与服务端

默认同时启用 client / server 仅为本地开发方便。发布客户端使用 `--no-default-features --features client`，不会把 ORM、HTTP 服务、MCP 服务或迁移依赖编入客户端；服务端使用对应 server feature。Web 是单独 workspace 包。

两个命令分别提供中文分层帮助，不混用本机接入命令和服务管理命令。客户端平台及镜像构建说明见 [Docker 部署](Docker部署.md)，本机构建见 [开发运行](开发运行.md)。

## 数据与检索

MySQL 是唯一权威数据源。记忆写入与任务登记处于同一事务；后台执行、重试、删除传播和重建。Qdrant 是可重建索引，返回前再次核对空间、当前修订及遗忘状态，不引入 Redis。

每个空间隔离原始证据、记忆、检索与来源。默认只搜索正式记忆；采集消息不自动变成长期记忆。MCP 当前有八个工具，能力快照使 Agent 在查询前知道关键词／混合检索状态，见 [MCP 接口](MCP接口设计.md)。

Embedding 为实例级可选能力，默认关闭。模型身份变化以新代际重建，地址与 API Key 不参与模型身份；模型故障时回退关键词。Secret 只将公开说明交给索引或模型。后台增量提取尚未实现。

## 安全与许可

空间是唯一隔离层，不增加用户或租户。用户 Web 登录与每 Agent 的 MCP／hook 凭据分开，Secret 取用须开启独立权限。原实例根私钥必须持久保存并独立备份，详情见 [空间与鉴权](空间与鉴权.md) 和 [Secret 加密](Secret加密选型.md)。
