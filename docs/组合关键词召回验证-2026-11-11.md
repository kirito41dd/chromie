# 组合关键词召回验证

本地实现与验证，尚未更新生产服务。改动保留既有模型的 0.56 相似度下限，只增加当前修订 BM25 候选的完整分段词面保护，规则见[模型设置与索引重建](模型设置与索引重建.md)。不新增模型、依赖、索引字段或数据库迁移。

## 验证方式

- 使用旧的 660 条阈值查询和 264 条短关键词查询作配对回归，复用原向量、真实 Qdrant BM25 Top 30、标签和划分，不重新选语义阈值。它们已经用于此前评测，不作为本次新的独立留出。
- 在私有记忆副本上固定正文和模型，用真实模型向量及真实 BM25 候选比较改动前后；再通过当前 Store 路径实际执行主要查询。只包含普通正文和 Secret 的公开说明，不读取 Secret 原文，也不修改生产记忆或配置。
- 用当前 Rust 策略源码判断 18,045 对查询与候选的词面证据，避免评测程序另写一套近似规则。评测代码、正文、向量、数据库定位和机器结果仅留在忽略目录，不能提交。
- 确定性低相似度模型的集成测试覆盖：组合主题词保留、缺失技术标识、空间／项目／修订边界、原精确短词、模型降级，以及 Web 与 MCP 返回一致。Web 诊断区分精确命中与完整分段覆盖，旧修订的证据不会展示到新正文。

## 限制

- 本次修复完整查询的词面组成分散在正文中的情况，不是通用的领域本体或查询改写。“数据库备份”在同一副本上仍为空；更长的自然问句仍可能遗漏总入口，不能据当前结果声称所有上位概念查询都已解决。
- 词面覆盖不理解否定、因果或对象关系。技术名称完整出现也不等于所求事实存在；Agent 仍须核对主体、环境与内容。
- 只保护已有且修订匹配的 BM25 候选；不增加候选池、不改变纯向量过滤、预算、故障降级或用户自定义阈值。无向量、旧修订、评分故障等原有边界沿用旧逻辑。
- 个人副本只是针对实际案例的补充验证；旧缓存上的复算不测线上 ANN、网络超时与真实数据长期变化。关联事实的过时与重复问题通过写入／修订指引改善，不在本次自动清洗生产记忆。
