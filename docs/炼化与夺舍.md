# 炼化与夺舍

“炼化”把一个空间的核心记忆下载为加密迁移包；“夺舍”把包追加到当前登录的空间。打开 Web 顶部的 **炼化／夺舍** 即可操作。

## 带走什么

- 当前未遗忘的记忆正文与项目范围。
- Secret 的公开说明、项目范围、格式契约，以及完整原文字节。
- 源空间、记忆 ID 与源修订，用于识别重复和展示迁入来源。

采集消息、原始证据关联、历史修订、召回与评价统计、向量、Agent 接入、登录态和模型设置不进入包。它是记忆迁移，不替代完整实例备份。

## 炼化

设置并确认独立的迁移口令，点击“炼化并下载”。尚未解锁时弹出空间验密，按钮明确显示“解锁并炼化”；取消不会导出。完成后得到 `.chromie` 文件。文件采用标准 age 口令加密，内部为版本化 JSON，无明文中间文件；下载的包与迁移口令应分开保管。丢失迁移口令无法解开文件，Chromie 不提供找回。

实例根私钥不进入迁移包。已有数据库仍须备份原根私钥，不能因为有炼化包就丢掉私钥；包也不包含原实例的接入密钥和历史数据。

## 夺舍

先登录目标空间，选择迁移包并输入其迁移口令，点击“预览内容”。尚未解锁时弹出空间验密，完成后继续预览。预览仅显示公开说明，不显示 Secret 原文。没选文件、口令不足或两次不一致时在当前表单说明，不靠隐藏条件静默置灰按钮。

- **新增**：目标没有该记忆 ID，确认后追加。
- **跳过**：同 ID、正文、范围、类型，以及 Secret 原文与契约都相同。
- **冲突**：目标同 ID 已有不同内容或已遗忘，保留目标内容，不自动覆盖。

摘要明确显示“等待确认 · 尚未导入”，旁边提供“确认夺舍”按钮。每页预览 5 条，通过上一页／下一页查看整个包。确认作用于整个包中的新增项，不只是当前页，也不支持逐条选择。失败不会留下部分记忆。成功后自动建立关键词索引；已启用 embedding 时也会加入当前模型队列。迁入记录从修订 1 开始，来源显示“迁入 · 源空间”。

如果全部跳过或冲突，会显示“无需夺舍”和原因，确认入口禁用；预览不会修改当前空间。若此包之前已经导入，则显示已有处理结果，不重复写入。

相同包重复提交直接返回原处理回执，不重复写入，也不复活随后遗忘的内容。另一次炼化是新包，仍按 ID 和内容判断。不同 ID 暂不做语义去重。

包内标准 `secret://源空间/UUID` 引用会改成目标空间引用。引用的 Secret 缺失或冲突时，依赖它的记忆也记为冲突，避免错误取用。其他空间的外部引用保留原文，不扩展访问权限。

预览后，本包涉及的目标记录若被更正、遗忘或另一次导入改变，翻页和确认都会要求重新预览。改密码会使旧登录失效。翻页继续验密并重新上传、解密原包，服务不缓存解密载荷；大包翻页可能需要更长时间。

## 边界

迁移仅允许 Web Cookie 登录并解锁，Agent MCP／hook 密钥不能迁移数据。页面可主动“解锁”，也可直接点击操作再按需验密；解锁后固定 10 分钟内可炼化、预览、翻页和确认，刷新与切页继续有效，状态查询不续期。授权只属于这次登录；“立即锁定”、退出或改密码后失效，服务重启需重新解锁。锁定阻止后续请求，不回滚已经提交的导入。

服务端只保存已验证登录 Cookie 的指纹、凭据版本和短期截止时间，不保留空间密码；浏览器不新增密码或解锁凭证的本地存储。迁移口令只随对应请求发送，离页即清除。已有调用方仍可使用原来每次提交空间密码的方式，但不能省略 Web 登录态。

Secret 原文由服务在内存中解密后精确比较，浏览器只得到新增／跳过／冲突；跨实例迁入使用目标实例根私钥重新加密。

首版每包最多 10,000 条记录，内部 JSON 最多 64 MiB，加密文件最多 65 MiB。实例同时只处理一项迁移，繁忙时可稍后重试。保留迁移口令和完整文件；错误口令、文件损坏、截断及不支持的版本都会拒绝导入。
