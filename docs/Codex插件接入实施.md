## 配置与权限

本地接入文件权限 0600，配置和队列目录 0700。setup 只接收文件路径；密钥不进命令参数、工具输出和插件包。用户级 Codex TOML 的合并必须保留其他 MCP、注释和设置，写入前备份，失败不截断文件。已存在不同的 Chromie 连接时拒绝静默覆盖。

首版直接注册现有 HTTP MCP，不增加协议代理或 OAuth。Codex 配置中的 MCP Authorization 与本地 hook 文件的上传密钥继续分离。配置重载是否需要新会话，以原生客户端实际状态为准。

用户已批准 `toml_edit`，用于保留配置结构和注释地合并 Codex TOML。

## 验收重点

- 仅名称创建、历史接入保留、安装方式切换不修改身份与密钥。
- 安装指南经过现有 MCP 鉴权，返回当前接入安全元数据，不泄露两枚密钥。
- setup 拒绝错误用途、非私有文件、符号链接、无效 TOML、连接冲突；保留其他配置，重复执行安全。
- 插件本身无凭据，实际 hook 通过独立上传密钥工作；离线仍沿用原有队列，不将消息注入终端日志。
- 连接检查区分工具发现、测试事件上传和真实 hook 收到消息；不以测试上传冒充客户端已启用 hook。
- Web 配置可预览、复制，桌面和窄屏可操作。

## 2026-10-29：切换接入页为空的修复

浏览器复现：从看板点击接入，列表为空；刷新同一地址可恢复。原因是 Rust 导航先 set_pages 并发起列表请求，随后 JS 更新地址时 hide_access_keys 递增请求代次并取消该请求，导致新列表永远无法回填。

调整为先完成地址切换及旧请求清理，再设置目标页面并加载数据，保留原有切页隐藏密钥和拒绝迟到响应的逻辑。浏览器已验证看板→接入、召回→接入、连续切换与历史后退／前进，均可显示两个既有演示接入。既有 13 项前端 Rust、44 项 JS 桥接测试，以及前端 lib check、Wasm Clippy、格式和 Web release 构建通过。未改鉴权、数据库或实例私钥。
