# 空间与鉴权

Chromie 鼓励个人私有化部署，只以空间隔离工作、生活等资料，不建立多用户、租户或成员体系。项目、标签和 Agent 名称用于组织与来源识别，不能替代空间权限。

## 入口与凭据

| 入口 | 凭据与边界 |
| --- | --- |
| Web 登录 | 当前空间密码，Argon2id 加盐哈希；成功后签发有效期 30 天的 ES256 JWT HttpOnly Cookie |
| Web 数据、接入管理与消息浏览 | 对应空间的 Web Cookie；不继承其他空间权限 |
| MCP | 当前 Agent 的独立 MCP Bearer 密钥，每次请求验证，不接受空间密码替代 |
| hook 上传 | 当前 Agent 的独立 hook Bearer 密钥，仅可上传，不可检索或读取 Secret |
| Agent Secret 存取 | MCP 密钥，且该接入已显式启用 Secret 权限；原文只通过本地 CLI／脚本的专用 HTTP 入口 |
| Web Secret 查看 | 在 Web 登录态之外再次验证空间密码；当前标签页固定 5 分钟复用验密，不续期 |
| 炼化／夺舍 | Web Cookie 加迁移解锁；再次验密后固定 10 分钟，同一登录会话跨刷新、切页有效 |

接入具有稳定 agent_id，来源由服务端鉴权绑定，不信任请求自报身份。每个 Agent 有独立的两类密钥，可查看、重置和整体停用，不必共享空间密码。详细生命周期见 [Agent 接入设计](Agent接入设计.md)。

空间密码更新后，旧密码与旧 Web JWT 的新请求失效；已经开始的处理不能撤回。Agent 密钥有独立生命周期，应通过重置／停用撤销。退出清除浏览器 Cookie 并撤销该会话的迁移解锁；服务不维护通用 JWT 黑名单，已复制的 Cookie 仍受原到期时间与改密失效约束。

## Web 与本机状态

Cookie 为 HttpOnly、SameSite，Secure 属性按配置的外部 Origin 是否 HTTPS 决定；数据接口保留 Origin 检查，不开放带凭据的通配跨域。

用户主动选择“记住密码”后，可在浏览器 localStorage 明文保存最近一组已验证的空间与密码用于预填；取消后清除，不自动用该密码登录。Secret 查看授权与迁移解锁均不自动复用这个已保存密码。

Secret 查看在刷新、退出或换空间时清除验密；原文浮层隐藏、关闭、切页或到期时清理。迁移解锁由后端绑定已验证的登录会话，立即锁定、退出或改密失效，服务重启后也需重新解锁；仅保留会话指纹、凭据版本和期限，不持久化空间密码。

## 空间与来源边界

固定入口形如 `/spaces/work-notes/mcp`，空间标识为小写英文与单个连字符。鉴权后构造可信空间上下文，工具参数不能切换到其他空间。

数据库查询、跨表关联、幂等回执、游标、索引、缓存、后台任务和来源均限定空间；检索返回前核对当前修订与遗忘。跨空间来源引用拒绝。记忆内容是资料，不能自动成为执行授权或覆盖用户指令。

Codex 采集接入后新增的用户文本及可取得的最终回复，保存会话、轮次、事件、角色、项目和时间。原始消息与正式记忆分开，普通原始消息不自动过期。暂停在本地写入前生效；上传失败保留原空间绑定及事件 ID，可补传，不向新空间改投。不额外归档全部工具输出、隐藏推理、附件正文或历史对话。

本地采集队列保存原始消息明文，Unix 目录为 0700、文件为 0600。当前不自动过滤聊天中的秘密，也不能撤回已经发给宿主模型的内容。Secret 专用流程见 [Secret 记忆](Secret记忆.md)。

## 实例与传输

实例根私钥用于 JWT 与按用途派生加密密钥，必须持久保存并与数据库分别备份。已有实例不能重新生成私钥来恢复旧密文。密码哈希、验密限速、并发预算和错误回显由服务端统一控制；日志不记录凭据、原文、SQL 参数或完整配置。

HTTP 和 HTTPS 均受支持，TLS 由部署或前置网关决定，不按公网／私网拒绝 HTTP；使用 HTTPS 时正常校验证书。密码鉴权不会对持有服务主机、原私钥或数据库访问权的部署者隐藏数据。更多部署与恢复说明见 [Docker 部署](Docker部署.md)。
