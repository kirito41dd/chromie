# 实例模型与混合检索

2026-11-03，用户确认实施。首版模型为已有 OpenAI 兼容接口的 text-embedding-v4，默认 1024 维。复用现有依赖；新增重要依赖仍须先确认。本次在当前 checkout 内联实施，不提交、不发布生产。

## 产品边界

- 模型配置属于整个实例。初始化空间获得系统设置能力，绑定内部 UUID；改名不改变权限。容器从已有 initialized.json 识别初始空间，已有开发实例通过本地管理配置明确指定；不能按请求中的空间名称或首次访问认领权限。
- 仅该空间的 Web 登录态能管理模型；MCP、hook 密钥不继承管理能力。其他空间只能查看自己的向量状态，不能取得其他空间名称、记忆或模型密钥。
- embedding 默认关闭，不改变原关键词检索、记忆、采集或 Secret 流程。首次启用后自动处理全实例有效记忆的当前修订；Secret 仅处理公开说明，不读取载荷，不处理原始对话。
- 系统设置显示当前模型、正在准备的模型及任务详情。Key 以独立用途派生的实例密钥加密保存，响应只提供是否已配置，不返回原文；不保存到浏览器本地存储。服务调用支持 HTTP/HTTPS，禁用重定向，错误不回显远端正文。

## 连接与模型代际

模型身份由模型名、用户可填的版本、维度、固定编码方式 plain-v1 决定；URL、API Key 不进入模型指纹。仅改连接沿用向量，连接测试不能证明两端模型语义一致，页面提醒核对版本并提供强制重建。模型、版本、维度或编码方式变化必须新建代际；即使维度相同也不能混用。

配置写入有修订检查。保存前以固定虚构文本测试接口、维度和有限非零数值，不上传真实记忆。更换模型确认框说明将重建全部空间的有效记忆、产生调用费用、旧模型仍可用时继续原检索，完成后自动切换。已有重建时替换须明确确认，取消代际的迟到结果不能发布或切换。

独立“测试连接”使用当前表单和同一条虚构文本，返回模型名、实际维度、耗时；与保存共用配置校验、已存 Key 选择和模型 HTTP 边界，但无数据库写入。测试入口同样限定初始管理空间的 Web Cookie。测试成功不启用模型或触发重建；保存时仍重新验证，不把之前的成功当作持续有效的授权或可用性证明。

## 持久化与一致性

SeaORM Rust migration 新增实例状态、模型代际、向量任务表，在隔离 MySQL 执行后反向生成 Entity。MySQL 保持权威，Qdrant 每空间、每代独立稠密索引，原 BM25 collection 保留。

- 全量扫描按空间与记忆组合游标分页，游标及扫描完成状态持久保存；所有空间包含后续新增空间。
- 记忆写入事务内登记当前代和构建代的增量任务，任务绑定 generation、space、memory、target_revision。数据库实例行协调任务登记、配置更新与最终切换，固定锁顺序，避免遗漏切换前后的写入。
- 涉及空间和向量任务时统一按空间 → 实例 → 向量任务加锁；配置操作不在持有实例锁后再申请空间锁，防止重试／清理与任务领取产生相反锁序。
- 任务领取有租约，模型调用在事务外。发布前重新核对代际、领取标识、记忆当前修订及遗忘状态；旧计算丢弃。短发布事务沿用空间锁，防止删除后迟到写回。
- 更正和遗忘传播覆盖活跃及构建代。停用时停止模型生成，删除清理继续执行；关键词任务独立运行。
- 扫描完成后检查每条当前有效记忆均已在新代完成当前修订，不能仅以队列暂空判定。短切换事务原子修改当前代。查询固定读取一代的配置与索引，候选再次经过空间、修订、遗忘状态校验。
- 未配置、停用、首次补建或模型故障时使用现有关键词检索。模型请求有短超时，有限重试后显示失败项；服务重启恢复游标及过期租约，任务结果按领取标识隔离。
- 旧索引保留足够的在途请求缓冲后异步清理；保留不代表可直接回滚到过期索引。回切同样按新代重建。清理不可删除当前或构建代，也不能触及 BM25 collection。

## 页面与召回

Header 增加仅管理空间可见的系统设置入口，继续使用 Slint。设置表单包含 Base URL、模型、Key、维度和可选版本；主要操作为保存并启用、更换并重建、停用，任务临时失败自动退避恢复，配置错误保存修正后恢复。索引维护位于底部，重建与停用使用红色短按钮和居中二次确认。密钥空值语义必须区分沿用和显式清除。

看板仅显示当前空间未配置／准备中／就绪／异常及覆盖数量。首次补建显示当前修订就绪数、总有效记忆数、待处理／运行／重试／失败数量和最后处理时间。重试次数不能算完成数量；扫描完成但未追平时显示追平变更。

recall 对外工具参数保持兼容，已配置且当前代可用时结合 BM25 与稠密候选，按 RRF 融合后仍使用原条数、正文预算和使用反馈。调试页展示语义可用性、模型代际、耗时、两路分数和融合排序；相似度不解释为准确率。

## 验收

必须覆盖：默认关闭兼容；管理空间与 Cookie 边界；Key 密文和错误不回显；跨空间隔离；首次补建与语义命中；同维换模型；改 URL／Key 不重建；强制重建；重建期间新增、更正、遗忘；暂停和服务重启；失败重试；取消及迟到结果；切换并发写入；旧代清理；Secret 只用公开说明；空库迁移和带数据升级。

测试只使用隔离 MySQL、Qdrant 与虚构模型 HTTP 服务；本机可展示功能，但真实模型质量需用户在设置页配置资源后另行验证。生产服务器保持现状，不自动启用或发送生产资料。
