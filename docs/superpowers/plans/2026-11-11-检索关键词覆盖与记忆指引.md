# 关键词证据与记忆可复用性优化

用户已批准优化并验证。当前工作区 Inline 实施，不提交、发布或修改生产数据；评测代码、实际记忆副本和机器结果仅放被忽略的本地目录。不新增依赖。

## 目标与边界

- 修复主题短语已取得关键词候选，却被统一语义门槛清空的问题。保持模型相似度下限及纯向量候选过滤，不无条件放行 BM25。
- 在关键词候选的当前修订上识别可解释的文本证据：原有完整词面命中继续保留；比较后选用完整分段覆盖：中文连续片段至少双字、不得漏字或重叠补齐，完整技术标识都要出现。不新增比例门槛，不能为特定系统硬编码词表。
- 显式技术标识缺失、单字巧合、只有部分通用字词均不能获得新豁免。覆盖只证明相关线索，不证明包含所问答案。
- MCP 与 Web 使用同一检索路径；保留空间／项目／遗忘／修订检查、预算、原有关键词降级和统计边界。诊断应区分精确词面与覆盖证据，不把低于阈值的保留项描述成语义通过。
- 写入指引面向无当前对话背景的读取者，按内容保留复用所需的主体、领域、条件、入口、方法和判断依据；避免固定模板，减少重复事实并提醒更正相关条目。生产记忆不在本次直接修订。

## 阶段

1. 用既有缓存的 660 条查询、短词回评和本次生产公开记忆副本比较规则；保留无关输入与对象不匹配负例。既有留出仅作回归，不宣称新的独立留出。
2. 在 `retrieval_policy` 实现无副作用的词面证据判断，在 `store/recall` 的现有候选过滤点接入并补诊断。只对修订匹配的 BM25 候选生效；不改变模型、索引格式或持久化结构。
3. 同步 Web 诊断、MCP 写入／检索指引和中文说明。使用虚构案例添加保护关键行为的确定性测试，实际评测资料不进仓库。
4. 本地隔离实例验证真实 BM25、确定性低相似度模型、两入口一致性及范围边界；适量真实模型对比生产副本。运行正式目标检查和相关测试，独立审查 Spec/Standards；修复阻塞后收尾。

## 验收

广义数据库运维查询能找回相关操作线索，精确系统查询保持；问候与明显无关输入不因新规则获得候选。对多个文本组成的查询，缺失显式技术标识不得放行。模型故障／未配置继续关键词能力，新修订不得承接旧修订的评分或覆盖证据。最终披露新保留的噪声与评测范围，不以少量正例宣称通用质量提高。
