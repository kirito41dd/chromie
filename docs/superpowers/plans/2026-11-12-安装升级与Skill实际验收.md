# 新版本安装、升级与 Skill 实际验收

用户同意补齐分发、实际安装升级和新会话使用验证；在当前工作区 Inline 执行，不提交、不推送、不部署生产。已有未提交功能和生产数据保持。本轮没有新增依赖计划。

1. 重新构建仅客户端功能的本机 CLI，生成当前平台下载程序、校验值及插件包，核对实际 HTTP 下载与 Skill 四个同源文件。其他平台没有实际构建／执行就不宣称验证。
2. 用独立目录和仅含虚构资料的测试实例执行安装、新接入和重复升级，使用真实 Codex 插件命令核对安装的 Skill 与 hook 清单。保留其他配置，既有凭据不进入对话、产物或输出；不更改 hook 信任记录或绕过审核。
3. 经用户确认有限模型用量后，最多运行两个临时 Codex CLI 会话，观察日常记忆、跨会话接续、关系、修订／反馈与 Secret 指引；只用虚构测试资料和隔离接入。不将控制器手工调用或后台模型任务等同于 Skill 自动加载效果，也不以一次成功承诺稳定遵从率。原始执行器与结果放忽略目录，不提交评测代码。
4. 核对自动整理遍历完毕后保持空闲、不重复调用的现有实现与回归，说明新增／更正、失败重试、对照主题与换模型后的边界，不新增无限周期重跑。
5. 更新人类可读的安装手册及验证记录。发现实际实现缺陷时按最小范围修复和对应检查；非平凡代码或分发安全行为变化按同轮 Spec／Standards 独立审阅收口。最终区分本机通过、其他架构／桌面客户端未运行、生产尚未发布，给出上线判断。

真实 Agent 验证的模型用量确认已异步提出；等待期间继续构建、打包、独立安装与源码核对，不发起依赖该确认的模型调用。生产私钥与数据不作为测试夹具，独立测试根私钥只写入新建测试目录。
