# 记忆引用、主题导航与后台整理实施计划

用户已同意先补引用、反向引用和主题导航，再增加关联读取、可选后台 LLM，并讨论随 CLI 分发日常使用 Skill。本轮在当前工作区分阶段 Inline 实施，不提交、不推送、不部署；保留此前未提交的关键词覆盖优化。重要依赖沿用现有库，不自行增加；文本模型由用户配置，不复用 embedding 配置或凭据。

后续确认：用户选择先实现 OpenAI 兼容接口，模型稍后配置。后台首版是 Rust 持久任务与结构化输出校验的固定工作流，不启动自主工具循环或外部 Agent；ACP 可在以后作为执行现成 Agent 的适配通道。用户显式选择范围后发起整理，持续自动提炼待真实质量与成本验证后演进。

## 产品与边界

记忆仍是空间内的稳定对象，正文的组织由 Agent 判断。新增主题记忆用于简短导航，链接到具体记忆；不强制每条普通记忆填写标题、机器或固定模板。结构化关系独立于正文，支持引用与派生依据。普通引用跟随当前记忆，派生依据保留目标修订，便于识别需要重新核对的摘要。同一事实更正仍优先修订原记忆。

所有读写维持空间、遗忘与修订边界。引用目标必须真实存在，不能以模型生成的 ID 建立关系；引用环允许，派生环拒绝。忘记依据时不能继续提供包含其信息的派生记忆。来源、关系、正文和索引任务须在同一空间写事务中提交；模型 HTTP 调用在事务外，写回前复核输入修订、来源状态和模型配置。

模型为实例级可选 OpenAI 兼容文本模型，地址、模型和密钥独立于 embedding。未配置时所有人工写入、引用、导航及检索照常工作。模型调用复用现有 UA、同名模型共享并发和按日用量统计。仅用户在设置中启用后运行，不访问 Secret 原文、密文或凭据配置，不把对话内容当作运行指令。

## 阶段与验证

1. **持久关系与协议。** 新增向前迁移，先在隔离 MySQL 执行，再从真实表反向生成 SeaORM Entity。扩展写入、更正、当前读取、反向引用与能力描述，保留旧客户端默认行为；验证空间隔离、幂等、更正时保留关系、过期依据和遗忘传播。
2. **主题导航与关联阅读。** 增加分页主题入口和有限邻接读取，Web 支持查看主题、引用及反向引用并顺着关系阅读。MCP 可发现主题导航；关联返回和直接命中明确区分，遵守范围和预算。迁移包同时携带节点类型与内部关系，导入时重映射实际 ID，旧包按普通记忆处理。
3. **可选文本模型与后台整理。** 实例设置提供连接测试、保存/停用及任务状态；持久任务在事务外调用模型并验证结构化结果。先用已保存记忆构建/更新简短主题、补充有依据的关系及报告冲突，再按同样的来源与修订规则支持采集材料的提炼。原有记忆不因模型猜测自动遗忘或静默覆盖。通过本机模拟模型验证连接、用量、重试、过时响应拒绝和可选能力降级。
4. **日常使用 Skill。** 随现有 Codex 插件/CLI 分发一个小入口，按需读取引用组织、接续与 Secret 取用说明；MCP 保留实时能力与最关键边界。Skill 传达目标，允许 Agent 自行组织；不把安装细节和整份教程注入每次 MCP 初始化。核对当前官方插件格式，验证打包与安装路径，不擅自改用户个人 AGENTS.md。
5. **集中验证与独立审阅。** 按正式 bin/lib 范围进行 fmt/check/clippy，运行保护新增契约的集成测试、Web Wasm 编译与本地浏览器走查。按 skill 要求完成实现后的独立 Spec/Standards 审阅，修复重要问题再交付。仅使用虚构空间/隔离库，不访问生产、不上传私有资料，不把私有评测代码纳入仓库。

## 重要实现约束

- MySQL 为唯一权威源，Qdrant 仍可重建；不为本轮引入图数据库或额外模型 SDK。
- `memory_sources` 的事件证据与记忆间关系分别表达，派生依据必须指定已读取修订。并发正确性用空间事务锁、修订校验和数据库约束保护。
- 关系读取有分页/数量上限；关联展开按预算受限，不因加入一条边自动灌入整张图。导航只保留主题和入口，正文详情按需读取。
- 后台生成内容保留依据与任务记录。配置切换、输入更正和遗忘均使旧任务不能发布；重试不会重复创建记忆。失败保留可理解的状态，不记录模型 Key、Secret 或原始响应到日志。
- 迁移包包含当前核心记忆及关系，不包含后台任务、接入凭据或原始消息。导入不能将冲突目标的 ID 误当作包内原目标；缺失/冲突关系须明确报告。
- 参照 type-driven-verification 的用例事务、类型边界、数据库演进与最小有效测试指导，不为仪式增加抽象或实现镜像测试。

## 完成依据

虚构的“数据库运维”主题能链接到两个操作记忆；Web 与 MCP 都能导航、读取反向引用。更正依据后能识别摘要需核对，遗忘后不再暴露依赖内容。未配置模型不影响以上流程；模拟模型能经过持久任务生成带依据的主题并在配置/来源过期时拒绝写回。CLI 安装产物包含可发现的日常使用 Skill，正文与 MCP 指引不存在相互矛盾。
