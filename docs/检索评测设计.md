## 三类评测分别报告

| 层次 | 数据与用途 | 不能据此声称什么 |
| --- | --- | --- |
| 公开检索基准 | 先选 C-MTEB 的 T2Retrieval，冻结完整 corpus、queries、qrels 和来源版本，检查中文通用检索与模型差异 | 不等于个人记忆、无答案识别或 Agent 使用效果 |
| Chromie 领域集 | 独立的虚构个人记忆、项目决定、偏好、公开 Secret 说明，以及相似干扰、更新、遗忘和空间隔离；用于调过滤与排序 | 合成数据不能当成真实用户总体分布 |
| Agent 端到端 | Agent 读历史、写入记忆、按当前能力查询，并依据取回证据完成任务；检查提取与使用错误 | 回答正确不证明检索、来源或权限全部正确 |

公开检索数据采用 [C-MTEB/T2Retrieval](https://huggingface.co/datasets/C-MTEB/T2Retrieval) 和[对应 qrels](https://huggingface.co/datasets/C-MTEB/T2Retrieval-qrels)。原始大文件放本地忽略目录，不进入业务数据库或 demo；执行所需清单、代码和产物也只保留本地。完整语料与抽样语料的结果必须明确分开，不能用小候选池的成绩冒充官方基准。

长期记忆测试参考 [LongMemEval](https://github.com/xiaowu0162/LongMemEval) 的跨会话、知识更新、时间推理和无答案场景。它要求从历史形成记忆再回答问题，不能把 oracle 答案会话直接变成我们的正式记忆库后宣称完成同一基准。适配时必须记录提取流程、读写 Agent 和模型版本；不得将问题、答案或证据标签泄漏给写入 Agent。oracle 仅用于诊断上限。

## 领域集与标注

起步规模建议为至少 1,000 条记忆、500 个问题，覆盖工作项目、开发排障、个人偏好、日程、生活及 Secret 公开说明；这是建设目标，尚不是已经完成的数据集。规模之外，更重要的是下列覆盖与标注质量：

- 精确编号、版本、别名、缩写；中文自然问法、短查询、同义改写及少量跨语言。
- 同名对象、相似项目、只差环境或日期的记录；旧决定被更正、记录已遗忘、跨空间禁止返回。
- 有答案和无答案分开。无答案应占有足够比例，并包含“对象存在但没记录该属性”的近似反例，不能主要靠“你好”等简单域外问题充数。
- 一个问题可有多条相关记忆。标注直接依据、辅助背景及已判断无关对象；未标注不自动等于已确认无关。需要组合多个事实时记录必需的证据组。
- 每条记录保留来源、作者／生成方式、标注与复核记录、适用时间和有效修订。模型生成样本必须另经复核，不能用同一生成模型的自评分代替独立标签。

建设时先冻结原始事实，再由未见检索结果的标注者写问题与标签。按事实家族／项目／更新链分组划分调参集和留出集；同一事实的多种改写不能分散到两侧。具体比例与随机种子写进版本清单，划分后不可按成绩移动样本。演示数据不混入正式留出集。

## 指标与调参规则

有答案问题报告 Hit@1/3/5/10、Recall@k、MRR 和 nDCG；Hit 表示至少命中一条，Recall 表示覆盖相关依据的比例，不能混用。组合问题另报证据组覆盖率。无答案问题报告非空误召回率和无关返回数量，有答案问题同时报告错误空结果率；不能只展示命中率而隐藏噪声。

按查询类型、语料长度和规模、语言、是否指定项目分别报告，至少比较 BM25、纯向量和实际混合流程。固定最大候选数、输出条数与正文预算，检查当前修订、遗忘及空间过滤；对同一查询配对比较，并给区间估计，避免少量样本的波动被当成稳定收益。

原始 BM25、余弦和融合分数分别保存，记录候选过滤前后数量与理由。阈值只在开发部分选取，再在冻结的留出部分验收；不能读取留出成绩后反复调到通过，也不能把 RRF 名次分数当成跨模型通用的置信度。模型名、版本／权重、维度、输入编码或语料分布变化后重新验证。改阈值不重算向量，改变向量输入编码则另建代际。

若不同模型的正负分数分布明显重叠，必须如实报告单阈值的局限，再讨论其他过滤或重排机制。正式指标目标在基线建立后明确；空间越界、已遗忘或过期修订泄露属于独立的正确性失败，不能被平均分抵消。

## 复现与运行边界

每次运行保存数据集版本与 SHA-256、标签／划分版本、代码版本和未提交差异、模型身份、输入编码、候选／预算／过滤参数、随机种子、时间、延迟、实际 Token 与失败／降级数量。模型故障和关键词降级单列，不能把降级结果混进模型正常质量分数。

向量缓存按模型身份、输入角色／编码和文本摘要隔离，避免换模型后复用旧向量。资源调用沿用模型共享并发与 UA；先做协议小检查，再运行规定规模。完整公开集的索引与问答需要单独估算调用量，不能因为数据下载完成就自动发起大批模型调用。本轮真实调用授权用于上述缩减语料阈值实验，不扩大成完整公开基准。

后续可积累经用户授权、去除敏感信息并复核的真实失败案例，独立版本化。Secret 只评估公开说明及引用；真实原文和凭据不进入评测集、日志、标注或模型。
