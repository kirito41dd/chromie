# 组织、引用与主题

普通记忆保存有复用价值的知识。按内容自然说明主体、必要条件和依据；操作经验按需保留入口、已验证方法、成功判断和关键注意事项。具体结构由你决定，不为凑字段扩写，也不堆同义词。

先用能力快照核对服务支持关系与主题。支持时，`remember` 的 `memory_type="topic"` 创建简短主题入口；正文第一行可作为人可读名称。主题只保留介绍和去向，详细事实集中在相应记忆中。普通条目用默认 `note`，不必额外建立主题。

`links` 中的 `memory_id` 必须来自真实读取或写入回执：

- `reference`：指向可继续阅读的对象，省略 revision，跟随其当前内容。
- `derived_from`：本条结论整理自目标内容，必须指定实际核对的当前 revision。依据变化会提示重新核对；不能只因相似度高就声称存在依据关系。

`correct_memory` 仍填写 expected_revision 和更正理由。省略 links 保留原关系；显式空数组清空。重新核对依据后，才更新派生修订。省略 memory_type 保留原类型。已知事件来源填写真实 source_refs，不能把另一条记忆的 ID 当作事件来源。

需要查看当前引用用 `get_memory_links`，incoming=true 查看反向引用；有 next_cursor 时按需继续。get_memory 的 knowledge.needs_review 表示派生依据已有变化，不意味着新旧哪条一定正确。比较来源、时间与适用范围，不能仅按更新时间判定事实。不同环境或历史事实允许并存。

遗忘会清除相关派生记忆，以免摘要继续保留用户要求忘掉的信息；普通导航引用不会扩大删除范围。主题、关联和摘要应帮助完成实际任务，避免无目的地增加边和重复总结。
