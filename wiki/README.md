## 阅读约定

- 每页描述现有行为，并给出相关源码、迁移或测试入口；业务规则不能只从表字段猜测。
- MySQL 是权威源，Qdrant 是可重建索引；原始采集、正式记忆和 Secret 原文分别处理。
- “后端强制校验”“提示词要求”“尚未实现”分别标明，模型的文本判断不写成确定性保证。
- 已支持引用、主题、按普通记忆修订自动整理、按原始事件持续提炼与会话命名，以及配套 Skill；自动沿关系扩展召回和 ACP 执行外部 Agent 尚未实现。原始对话处理有独立开关，默认关闭。

## 怎样维护

功能、协议、表结构、状态机或安全边界变化时，在同一改动中更新对应页；新增页面同时加入本索引，并链接相邻主题。优先修改已有章节，避免为同一机制再建一份独立长文。

表字段、主键和索引集中维护在 [数据模型](数据模型.md)，功能页解释使用方式。迁移是数据库结构依据，生成 Entity 不手工修改；设计意图与当前实现不同的地方直接说明。

使用手册负责操作入口和用户可见行为，Wiki 负责内部机制，阶段计划只记录实施过程。涉及这些层面的改动同时检查相关链接，避免用户手册与实现说明互相矛盾。

所有例子使用虚构资料。真实地址、凭据、私钥、数据库快照与私有验收日志不进入 Wiki。记录新验证结果时写明范围，不把模拟模型通过解释为真实模型质量通过。
